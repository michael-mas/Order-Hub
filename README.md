# Michael Mas — portfolio

Site personnel : développeur full stack, PHP/Symfony et React/TypeScript,
intégrations e-commerce.

## Commandes

| Commande         | Rôle                                                    |
| ---------------- | ------------------------------------------------------- |
| `npm run dev`    | Serveur de développement                                |
| `npm run verify` | Typecheck + lint + format + tests unitaires — bloquant  |
| `npm run e2e`    | Tests de bout en bout (Playwright, build de production) |
| `npm run build`  | Build de production                                     |

## Règles

- Tout fait de carrière vient de `src/content/profile.ts`, dérivé de
  `docs/PARCOURS.md`. Nulle part ailleurs.
- TypeScript strict, lint sans avertissement, tests verts : sinon rien ne part.
- La page est complète sans JavaScript et sans 3D.

Journal des décisions : `docs/JOURNAL.md`.
